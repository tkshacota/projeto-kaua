# Portfólio de estudos

Página de apresentação criada como exercício introdutório de HTML e CSS. O conteúdo atual descreve estudos e projetos de portfólio, sem incluir idade, data de nascimento ou e-mail escolar.

## Ver a página

Abra `index.html` em um navegador. O site contém uma breve apresentação, projetos pessoais/de estudo e links para GitHub e LinkedIn.

## Tecnologias

- HTML semântico
- CSS responsivo

Os projetos listados na página usam exemplos sintéticos e não representam experiência profissional.
